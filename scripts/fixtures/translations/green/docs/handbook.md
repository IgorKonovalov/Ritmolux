# The handbook

A source document with a translation beside it. Nothing here is broken: this tree is the half of
the fixture that passes, and what it asserts is that the gate measures the pair it should and stays
silent about everything else.

## The stamp this document does not carry

A source is not a translation and must never be read as one, even when it talks about the syntax:

```markdown
<!-- translated-from: 3614c87 -->
```

That fenced line is why this section is here. A gate that looked for the phrase rather than for the
`.ru.md` suffix would convict this file, and every document that ever explains the convention with
it.
