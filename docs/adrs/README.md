# Architecture Decision Records

Numbered, append-only records of decisions that have a rejected alternative worth
remembering. Accepted ADRs are never edited in place — to change a decision, write a new
ADR that supersedes the old one and update the status here.

Rule of thumb: if you can't name an option you're *not* taking, you don't need an ADR —
you need a code comment.

Decision: a `[mesh]` table of inline vertices and triangle indices, parsed once at load, with the tier's particle budget scattered by **area-weighted barycentric sampling seeded on the particle index**; the same data strokes as a wireframe through the existing line renderer; **density becomes a property of the tier, not the asset**, so one blob feeds both tiers and [ADR-0069](0069-the-attractor-trades-sample-count-for-trace-length.md)'s `density` applies unchanged. No C ABI change, no asset path, no file IO, no new dependency — which is exactly why "both frontends" costs nothing, and it **extends** [ADR-0107](0107-an-authored-path-is-inline-svg-data-and-it-morphs-by-resampling.md)'s self-containment precedent rather than superseding it. Rejected: **a baked point cloud inline** (the ~75x arithmetic, and it freezes density into the asset), **a runtime asset directory** (ADR-0107's own rejected Alternative D, compounded here — the foobar cdylib has no asset root, so it needs a thirteenth ABI function per [ADR-0003](0003-c-abi-v1-surface.md), plus a glTF crate against NFR 4), **rasterize a lit mesh** (first depth buffer *and* first non-emissive register, against a composite, bloom bright-pass, [ADR-0056](0056-additive-scenes-emit-premultiplied-alpha.md) alpha-as-falloff and trail accumulator that all assume emission), **bake to a 3D SDF and raymarch** (the strongest loser — lands on [ADR-0105](0105-the-mark-roster-becomes-a-fullscreen-distance-field.md)'s machinery and would deliver backlog 0092's shading incidentally, but a 128³ field is ~2 MB so the asset cannot be inline, and a baked SDF is **frozen geometry** whose displacement breaks the march's Lipschitz bound — killing the deformation asked for), and **build-time embed from the repo** (the near-miss: keeps self-containment and **lifts the triangle ceiling**, but turns content into code so only a developer could add a model, answering a different question than the one asked). Costs: **uniform sampling gives flat density, the opposite of what makes the attractors beautiful**, and it is **worse on hard-surface models than organic ones** (area weighting washes a flat face and gives a silhouette edge no emphasis) — both kinds are in scope and only one is well served; the author must **decimate to ~500 triangles**; a **rigid figure saturates the trail field**, so a motionless model is not a supported look; **occlusion is absent and here it reads as a defect** rather than as the medium, because the viewer knows what the shape should hide; and a preset stops being readable, again. Every number is **construction arithmetic, not measurement** — a plan owes the recognizable-silhouette triangle count and a walking-skeleton check that uniform sampling reads at all.
