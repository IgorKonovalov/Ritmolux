Ritmolux runs as a **standalone app** on Windows and macOS, or as a **foobar2000
component**. It reads the audio, not a file — so it draws to a browser tab, a game, or a
music player just the same. Every look it ships is a **preset**: a text file you can open,
read, and change.

## What it looks like

One frame from each rendering system. Every one of them is a preset.

export const gallery = Object.entries(
  import.meta.glob('../../../../docs/images/gallery/*.png', { eager: true, import: 'default' }),
)
  .map(([file, image]) => ({ image, system: file.split('/').pop().replace('.png', '') }))
  .sort((a, b) => a.system.localeCompare(b.system));
